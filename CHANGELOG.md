# Changelog

## 0.9.0 - 2026-10-17

Initial local Windows preview for The Thrifty Pilot.

- Added secure Electron shell, React interface, guided setup, original icon, dark/light themes and nine working navigation sections.
- Added aircraft profiles, archive/duplicate operations, currency safeguards and explicit unknown assumptions.
- Added decimal-based cash/economic/forecast separation, utilization sensitivity, unit conversion and manual/derived engine reserves.
- Added recurring plans, partial-payment/prepayment reconciliation, payment classification, local receipts and CSV import/export.
- Added flight logging with separate meter bases, measured fuel, explicit trip-fee inclusion, and multi-leg trip estimates with saved assumption snapshots.
- Added maintenance reminders, cash budgets, eight ownership report types, trip PDFs, CSV summaries, printing and paginated tables.
- Added SQLite versioning, foreign keys, transactional writes, portable verified backups, restore rollback and startup recovery preserving original files.
- Added automated financial/persistence/reporting tests and Electron workflow tests, including offline and packaged execution.
- Generated an unsigned Windows x64 NSIS installer. Public publishing and licensing are not part of this build.
